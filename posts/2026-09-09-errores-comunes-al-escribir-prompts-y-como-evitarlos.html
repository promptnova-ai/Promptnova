Errores comunes al escribir prompts y cómo evitarlos

2026-09-09 · 5 min de lectura · prompt engineering IA productividad errores comunes

Introducción

En la práctica diaria de la inteligencia artificial, la calidad del resultado depende en gran medida de la claridad del prompt. Un prompt confuso, impreciso o incompleto puede generar respuestas irrelevantes, sesgadas o simplemente inútiles. En este artículo analizamos los errores más habituales que cometen tanto principiantes como usuarios avanzados y ofrecemos soluciones concretas para evitarlos.

Errores comunes

1. Prompt demasiado vago

Solicitar algo genérico como "escribe un artículo" deja al modelo sin criterios de longitud, tono o enfoque, lo que suele producir textos extensos y poco estructurados.

Prompt: "Escribe un artículo sobre IA."

2. Falta de contexto relevante

El modelo no tiene acceso a información externa a menos que se la proporcionemos. Omitir datos clave obliga a la IA a adivinar y aumenta la probabilidad de errores.

Prompt incorrecto: "Resume el informe de ventas del Q3."
Prompt correcto: "Resume el siguiente fragmento del informe de ventas del Q3: [pega el texto]."

3. Instrucciones contradictorias

Combinar requisitos opuestos (por ejemplo, "escribe un texto breve pero muy detallado") confunde al modelo y genera resultados incoherentes.

"Cuando las instrucciones se contradicen, el modelo prioriza la última cláusula que reconoce."

4. Ignorar el formato de salida

Si necesitas una tabla, una lista con viñetas o código, especificarlo explícitamente evita que la IA devuelva párrafos corridos.

Prompt: "Proporciona una tabla Markdown con los principales algoritmos de clustering y sus características."

5. No especificar tono o audiencia

Un texto técnico para expertos y otro divulgativo para principiantes requieren estilos diferentes. Sin esa guía, el modelo suele elegir un tono neutro que puede no encajar.

Prompt: "Explica la diferencia entre aprendizaje supervisado y no supervisado para estudiantes de secundaria."

Cómo evitarlos: buenas prácticas

  • Define el objetivo claramente. Pregúntate: ¿qué tipo de respuesta espero? (lista, tabla, ensayo, código).
  • Incluye contexto suficiente. Añade datos, ejemplos o fragmentos de texto que el modelo deba considerar.
  • Usa un lenguaje estructurado. Emplea viñetas, numeraciones o marcadores para separar requisitos.
  • Especifica formato y tono. Indica si deseas Markdown, JSON, estilo formal, casual, etc.
  • Prueba iterativamente. Genera una versión corta, revisa y refina el prompt antes de la versión final.

Ejemplos listos para copiar

A continuación encontrarás ocho prompts listos para usar, con una breve explicación del caso de uso.

#1 Generación de contenido SEO
Prompt: "Escribe un artículo de 800 palabras sobre los beneficios del teletrabajo, con encabezados H2, una conclusión y al menos tres estadísticas (cita fuentes ficticias). Usa tono cercano y dirige el texto a emprendedores."
---
#2 Creación de tabla comparativa
Prompt: "Genera una tabla en formato Markdown que compare los principales modelos de lenguaje (GPT‑4, Claude‑2, Gemini) en cuanto a tamaño, número de parámetros y casos de uso recomendados."
---
#3 Resumen de documento largo
Prompt: "Resume los siguientes 1500 caracteres del informe financiero (pega el texto) en tres párrafos, destacando ingresos, gastos y proyecciones."
---
#4 Conversión a JSON estructurado
Prompt: "Convierte la siguiente lista de productos en un array JSON con campos: nombre, precio, categoría y disponibilidad. Lista: Apple iPhone 14 – $799 – Smartphone – En stock; Samsung Galaxy S23 – $749 – Smartphone – Agotado."
---
#5 Código de ejemplo en Python
Prompt: "Escribe una función en Python que reciba una lista de números y devuelva la media, manejando listas vacías sin lanzar excepción. Incluye docstring y pruebas unitarias simples."
---
#6 Redacción de correo formal
Prompt: "Redacta un correo electrónico dirigido al departamento de recursos humanos solicitando una revisión salarial, manteniendo tono respetuoso y citando logros del último año."
---
#7 Generación de preguntas de examen
Prompt: "Crea diez preguntas de opción múltiple sobre la teoría de grafos, con cuatro alternativas cada una y la respuesta correcta marcada."
---
#8 Guía paso a paso para usuarios novatos
Prompt: "Elabora una guía paso a paso (con viñetas) para crear una cuenta en ChatGPT, indicando capturas de pantalla ficticias y consejos de seguridad."

Verificación de resultados y límites

Incluso con prompts bien estructurados, la IA tiene limitaciones: conocimiento actualizado hasta la fecha de corte, falta de acceso a datos privados y posible sesgo en los entrenamientos. Para comprobar si el resultado mejora:

  • Revisa la precisión factual. Contrasta datos y cifras con fuentes fiables.
  • Evalúa la adherencia al formato. Usa validadores de JSON, Markdown o HTML según corresponda.
  • Prueba con métricas de legibilidad. Herramientas como Flesch‑Kincaid pueden indicar si el tono coincide con la audiencia.
  • Solicita una segunda versión. Pide al modelo que reescriba o refine el output para detectar inconsistencias.

Caso práctico: de la idea al prompt final

Objetivo: Generar una infografía sobre los pasos del proceso de onboarding para una startup tecnológica.

  1. Definir la salida. Necesitamos una lista estructurada de 6 pasos, cada uno con título, descripción breve y tiempo estimado.
  2. Recopilar contexto. Proporcionamos ejemplos de pasos comunes (registro en la plataforma, configuración de correo, etc.).
  3. Redactar el prompt inicial.
Prompt inicial: "Crea una lista de los pasos del proceso de onboarding en una startup de software. Cada paso debe incluir título, descripción y tiempo estimado. Usa formato JSON."

Resultado: La IA entrega una lista incompleta y sin tiempos. Identificamos dos fallos: falta de detalle y ausencia de formato de tiempo.

  1. Refinar el prompt. Añadimos especificaciones de formato y ejemplos.
Prompt refinado: "Genera un array JSON llamado 'onboarding' con 6 objetos. Cada objeto debe contener: 'paso' (título corto), 'descripcion' (máximo 30 palabras) y 'tiempo' (en días). Usa los siguientes ejemplos como guía: {\"paso\": \"Registro en la plataforma\", \"descripcion\": \"Crear cuenta y verificar email\", \"tiempo\": \"0.5\"}."

Resultado mejorado: La respuesta incluye los 6 pasos, con tiempos claros y estructura válida. Verificamos el JSON con un validador online y confirmamos que la información coincide con nuestras expectativas.

Checklist accionable

  • ¿He definido claramente el tipo de salida (texto, tabla, JSON, código)?
  • ¿Incluyo todo el contexto necesario (datos, ejemplos, fragmentos)?
  • ¿El prompt está libre de ambigüedades o contradicciones?
  • ¿He especificado tono, audiencia y estilo?
  • ¿He indicado el formato de presentación (Markdown, HTML, lista, etc.)?
  • ¿Realizo una prueba rápida y valido el resultado con herramientas externas?
  • ¿Itero al menos una vez para pulir la respuesta?
