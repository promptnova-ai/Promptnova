Construye tu propio asistente personal con ChatGPT y prompts

2026-09-03 · 5 min de lectura · ChatGPT asistente personal prompt engineering

¿Qué es un asistente personal basado en IA?

Un asistente personal impulsado por ChatGPT es un programa que, mediante el modelo de lenguaje de OpenAI, interpreta tus instrucciones y ejecuta tareas como gestionar agenda, responder correos o buscar información. La clave está en los prompts, que definen el comportamiento y el tono del asistente.

Diseñando los prompts básicos

El primer paso es redactar un prompt maestro que establezca el rol del asistente y sus limitaciones. A continuación, se pueden crear sub‑prompts para cada función específica.

Prompt maestro

Actúa como un asistente personal amigable y proactivo.
Responde siempre de forma concisa, menciona la hora actual y
pregunta si deseas más información antes de ejecutar cualquier acción.

Prompt para gestión de calendario

Eres el asistente de calendario de Juan.
Cuando reciba una petición como "Programa una reunión el viernes a las 10",
consulta la disponibilidad en Google Calendar y devuelve la confirmación.

Prompt para redacción de correos

Redacta un correo profesional a [destinatario] con el asunto [asunto] y los puntos clave: [lista].
Mantén el tono cordial y cierra con "Saludos".

Integración con APIs y herramientas

Para que el asistente realice acciones fuera del texto, es necesario conectarlo a APIs externas. La arquitectura típica incluye:

  • Una capa de webhook que recibe la respuesta de ChatGPT.
  • Funciones auxiliares que llaman a servicios como Google Calendar, Gmail o Notion.
  • Un motor de enrutamiento que decide qué función ejecutar según el contenido del prompt.

En Node.js, por ejemplo, podrías usar axios para hacer peticiones HTTP y openai SDK para enviar los prompts.

Ejemplos de prompts listos para copiar

A continuación tienes tres prompts que puedes copiar y adaptar inmediatamente:

# 1. Resumen de noticias diarias
"Eres un asistente de noticias. Resume en tres viñetas las noticias más relevantes de hoy en tecnología, finanzas y salud."
# 2. Generador de listas de compras
"Eres un asistente de compras. Dada la frase 'Necesito ingredientes para una paella', genera una lista de compra con cantidades estimadas."
# 3. Recordatorio de seguimiento
"Eres un asistente de seguimiento. Cada lunes a las 9 am, envía un mensaje a mi equipo recordando actualizar el reporte semanal."

Consejos para mejorar la interacción

  • Usa contexto limitado: Incluye solo la información necesaria en cada petición para evitar respuestas largas.
  • Define formatos de salida: Pide respuestas en JSON o en listas con viñetas para facilitar el procesamiento automático.
  • Itera y prueba: Ajusta los prompts después de cada prueba real y registra qué variantes producen mejores resultados.
“Un buen prompt es la diferencia entre un asistente que adivina y uno que comprende.” – Prompt Engineer

Con estos pasos y ejemplos, ya puedes montar tu propio asistente personal con ChatGPT, adaptarlo a tus flujos de trabajo y seguir mejorándolo con nuevas funciones. ¡Empieza hoy y automatiza tu día a día!
