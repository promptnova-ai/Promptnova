Construye tu propio asistente personal con ChatGPT paso a paso

2026-09-15 · 5 min de lectura · ChatGPT asistente personal prompt engineering IA automatización

Introducción

Los asistentes personales basados en IA han pasado de ser una idea de ciencia ficción a una herramienta accesible para cualquier persona con una cuenta de OpenAI. En este artículo descubrirás cómo montar uno propio usando ChatGPT y una serie de prompts bien diseñados. No necesitas conocimientos profundos de programación; la clave está en estructurar la conversación y gestionar el contexto.

Preparación del entorno

Antes de escribir código, asegura lo siguiente:

  • Una clave API de OpenAI con permisos de chat/completions.
  • Un entorno de ejecución (puede ser un script Python, una función en Google Cloud, o incluso Zapier).
  • Una forma de almacenar el historial de la conversación (archivo JSON, base de datos ligera o memoria en sesión).

Con estos requisitos cubiertos, puedes pasar a diseñar la lógica del asistente.

Diseño de la arquitectura básica

Un asistente típico se compone de tres capas:

  1. Entrada del usuario: texto libre o comando estructurado.
  2. Motor de IA: llamada a ChatCompletion.create con un prompt que define el rol y las instrucciones.
  3. Salida procesada: formato de respuesta (texto, lista de tareas, JSON, etc.) y acciones posteriores (ejecutar un script, enviar un correo, etc.).

Esta separación permite reemplazar cada capa sin afectar a las demás y facilita pruebas unitarias.

Ejemplos de prompts reutilizables

A continuación tienes cinco prompts listos para copiar. Cada bloque está envuelto en <pre><code> y lleva una breve explicación de cuándo usarlo.

# Prompt 1 – Definir el rol del asistente
Eres un asistente personal llamado Ayudín. Tu objetivo es responder preguntas, organizar agendas y ofrecer recordatorios breves. Mantén siempre un tono amable y conciso.
# Cuándo usarlo
Al iniciar la conversación o al resetear el contexto, para que el modelo conozca su personalidad y limitaciones.
# Prompt 2 – Gestión de agenda
Actúa como un gestor de agenda. Cuando el usuario mencione una fecha y una tarea, devuelve un JSON con los campos: "fecha", "tarea" y "prioridad" (alta, media, baja).
# Cuándo usarlo
Para convertir texto natural en datos estructurados que puedas guardar en una base de datos o calendario.
# Prompt 3 – Resumen de conversación
Resume los últimos tres intercambios en no más de 50 palabras, destacando decisiones y acciones pendientes.
# Cuándo usarlo
Al final de una sesión larga, para ofrecer al usuario un recapitulativo que facilite la continuidad.
# Prompt 4 – Búsqueda de información externa
Simula una búsqueda web: responde con una lista de tres fuentes confiables (URL) que traten el tema solicitado, sin inventar contenido.
# Cuándo usarlo
Cuando la respuesta requiera datos actualizados o referencias verificables.
# Prompt 5 – Manejo de errores y reintentos
Si no entiendes la petición, responde: "Lo siento, no he captado bien. ¿Podrías reformularlo?" y registra el intento.
# Cuándo usarlo
Como fallback antes de abortar la conversación, para mejorar la experiencia del usuario.

Caso práctico: asistente de planificación diaria

Desarrollaremos un asistente que permite al usuario crear su agenda del día con comandos de voz o texto. El flujo será:

  1. Saludo inicial y establecimiento del rol (Prompt 1).
  2. El usuario dice: "Reúnete con Marta el 12 de junio a las 10 am para revisar el proyecto".
  3. Se envía el mensaje al modelo junto con Prompt 2 para obtener JSON.
  4. El JSON se guarda en una tabla SQLite.
  5. Al final del día, el asistente genera un resumen usando Prompt 3 y lo envía por correo.

Implementación mínima en Python (solo fragmento representativo):

import openai, json, sqlite3

openai.api_key = "TU_CLAVE_API"

def llama_chat(messages):
    resp = openai.ChatCompletion.create(
        model="gpt-4o-mini",
        messages=messages,
        temperature=0.2
    )
    return resp.choices[0].message.content

# 1. Rol
system = {"role": "system", "content": "Eres un asistente personal llamado Ayudín. ..."}

# 2. Entrada del usuario
user = {"role": "user", "content": "Reúnete con Marta el 12 de junio a las 10 am para revisar el proyecto"}

# 3. Prompt de agenda
agenda_prompt = {"role": "assistant", "content": "Actúa como un gestor de agenda..."}

response = llama_chat([system, user, agenda_prompt])
data = json.loads(response)

# 4. Guardar en SQLite
conn = sqlite3.connect('agenda.db')
cur = conn.cursor()
cur.execute('CREATE TABLE IF NOT EXISTS tareas(fecha TEXT, tarea TEXT, prioridad TEXT)')
cur.execute('INSERT INTO tareas VALUES (?,?,?)', (data['fecha'], data['tarea'], data['prioridad']))
conn.commit()
conn.close()

Este ejemplo muestra cómo combinar varios prompts para pasar de texto libre a datos estructurados y, finalmente, a una acción concreta (almacenar en base de datos).

Verificación de resultados

Para comprobar que el asistente está funcionando correctamente, sigue estos pasos:

  • Revisa que el JSON devuelto cumpla con el esquema esperado (puedes usar jsonschema).
  • Ejecuta una consulta a la base de datos y verifica que la fila coincida con la entrada.
  • Simula un día completo y comprueba que el resumen generado contiene todas las tareas sin omisiones.

Límites, errores frecuentes y cómo mitigarlos

ChatGPT no tiene acceso a datos en tiempo real ni a tu calendario a menos que tú le proveas la información.

Los problemas más habituales son:

  • Contexto truncado: si la conversación supera los 4 k tokens, el modelo olvida los primeros mensajes. Solución: resumir el historial o usar una base de datos externa.
  • Interpretación ambigua: frases como "próxima reunión" pueden referirse a distintas fechas. Solución: solicita siempre la fecha explícita o usa un prompt de aclaración.
  • Formato JSON inválido: el modelo a veces genera comas de más o faltan comillas. Solución: envolver la petición en un try/except y volver a solicitar el formato.
  • Límites de la API: número máximo de peticiones por minuto. Solución: implementar caché y back‑off exponencial.

Checklist accionable

  • ✅ Obtén y protege tu clave API.
  • ✅ Define claramente el rol del asistente (Prompt 1).
  • ✅ Implementa una capa de almacenamiento para el historial.
  • ✅ Crea prompts específicos para cada función (agenda, resumen, búsqueda).
  • ✅ Valida siempre la salida JSON contra un esquema.
  • ✅ Añade manejo de errores y reintentos (Prompt 5).
  • ✅ Prueba el flujo completo con casos de uso reales.
  • ✅ Documenta los límites de token y la política de uso de la API.
