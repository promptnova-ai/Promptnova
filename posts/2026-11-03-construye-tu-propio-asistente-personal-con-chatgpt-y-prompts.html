Construye tu propio asistente personal con ChatGPT y prompts

2026-11-03 · 5 min de lectura · ChatGPT asistentes personales prompt engineering

Introducción

Los asistentes personales basados en IA están cambiando la forma en que organizamos nuestras tareas, gestionamos la información y automatizamos procesos cotidianos. Gracias a la API de ChatGPT y a una buena estrategia de prompt engineering, puedes crear un asistente que responda a tus necesidades sin depender de soluciones propietarias.

Arquitectura básica del asistente

Una arquitectura mínima incluye tres componentes:

  • Interfaz de usuario: puede ser un bot de Telegram, una aplicación web o un script de línea de comandos.
  • Motor de generación: la llamada a la API de ChatGPT, configurada con model, temperature y max_tokens.
  • Gestor de contexto: almacena historial, variables de sesión y reglas de negocio para que el asistente mantenga coherencia.

Esta separación permite escalar y depurar cada parte por separado.

Ejemplos de prompts reutilizables

A continuación se presentan ocho prompts listos para copiar. Cada bloque incluye una breve explicación de cuándo usarlo.

# Prompt 1 – Resumen rápido de texto
Eres un asistente conciso. Resume el siguiente texto en 3 frases sin perder información clave:
"{{texto}}"

Útil para procesar correos largos o documentos antes de guardarlos.

# Prompt 2 – Lista de tareas a partir de una descripción
Actúa como un planificador. Dado el siguiente objetivo, genera una lista de tareas accionables con prioridad:
"{{objetivo}}"

Ideal cuando el usuario escribe algo como "Necesito organizar mi viaje a Madrid".

# Prompt 3 – Conversación de seguimiento
Eres un asistente que mantiene contexto. Responde a la última pregunta del usuario basándote en el historial anterior:
{{historial}}
Usuario: {{pregunta_actual}}

Este prompt se usa en cada intercambio para preservar la memoria a corto plazo.

# Prompt 4 – Conversión de unidades
Convierte la siguiente medida al sistema métrico (o al que prefiera el usuario):
"{{medida}}"

Práctico en asistentes de cocina o de ingeniería.

# Prompt 5 – Generación de correo electrónico formal
Redacta un correo formal con tono respetuoso. Usa la siguiente información:
Asunto: {{asunto}}
Destinatario: {{destinatario}}
Cuerpo: {{cuerpo}}

Ayuda a usuarios que necesitan escribir rápidamente correos profesionales.

# Prompt 6 – Respuesta con fuentes citadas
Responde a la pregunta proporcionando al menos dos fuentes verificables (enlace o referencia):
"{{pregunta}}"

Fundamental para evitar la propagación de información no verificada.

# Prompt 7 – Diagnóstico de errores de código
Eres un depurador. Analiza el siguiente fragmento de código y sugiere la causa más probable del error:
"{{codigo}}"

Perfecto para asistentes orientados a programadores.

# Prompt 8 – Recordatorio de agenda con prioridad
Genera un recordatorio amigable basado en la siguiente entrada del calendario, indicando prioridad y tiempo restante:
"{{evento}}"

Se activa automáticamente cuando el usuario pide "¿Qué tengo hoy?".

Casos de uso concretos

Los prompts anteriores pueden combinarse para crear flujos complejos. Por ejemplo, un usuario pide organizar una reunión:

  • Prompt 2 para generar la agenda.
  • Prompt 5 para redactar la invitación.
  • Prompt 8 para crear el recordatorio.

Al encadenar respuestas, el asistente actúa como un verdadero ayudante de productividad.

Desarrollo de un caso práctico de principio a fin

Objetivo

Construir un asistente que, al recibir un correo de cliente, extraiga la acción requerida, genere una respuesta y programe un recordatorio.

Paso 1 – Configuración del entorno

  • Crear una cuenta en OpenAI y obtener la clave API.
  • Instalar la librería openai en Python: pip install openai.
  • Definir variables de entorno para la clave y el modelo (p. ej., gpt-4o-mini).

Paso 2 – Implementar la llamada a la API

import os, openai
openai.api_key = os.getenv('OPENAI_API_KEY')

def chat(prompt):
    response = openai.ChatCompletion.create(
        model='gpt-4o-mini',
        messages=[{'role':'system','content':'Eres un asistente profesional.'},
                  {'role':'user','content':prompt}],
        temperature=0.2,
        max_tokens=500
    )
    return response.choices[0].message.content.strip()

Paso 3 – Extracción de acción

Usamos el Prompt 1 adaptado para detectar la tarea principal del correo:

prompt = f"Eres un asistente que identifica la acción principal en correos. Extrae la acción y el plazo si existe. Correo:\n'''{correo}'''"
accion = chat(prompt)

Paso 4 – Generación de respuesta

Con la acción obtenida, aplicamos el Prompt 5 para redactar la respuesta:

respuesta_prompt = f"Redacta un correo de confirmación para el cliente. Acción: {accion}. Mantén tono cordial y profesional."
respuesta = chat(respuesta_prompt)

Paso 5 – Programar recordatorio

Si la acción incluye una fecha, utilizamos Prompt 8 para crear el recordatorio que se enviará a Google Calendar (o a un bot de Telegram):

recordatorio_prompt = f"Genera un recordatorio amigable para la siguiente tarea: {accion}."
recordatorio = chat(recordatorio_prompt)
# Aquí se llamaría a la API de Calendar para crear el evento

Paso 6 – Verificación de resultados

Para validar que el asistente funciona correctamente, seguimos una checklist:

  • ¿El texto extraído corresponde a la acción real del correo?
  • ¿La respuesta generada contiene todos los datos necesarios?
  • ¿El recordatorio incluye fecha y prioridad correctas?

Si alguna respuesta falla, ajusta la temperatura o agrega ejemplos en el prompt (few‑shot).

Checklist accionable

  • ✅ Definir el modelo y la temperatura adecuada.
  • ✅ Crear prompts base y guardarlos en un archivo de referencia.
  • ✅ Implementar gestión de historial para mantener contexto.
  • ✅ Añadir lógica de reintento ante errores de red o respuestas vacías.
  • ✅ Probar cada prompt con al menos tres ejemplos reales.
  • ✅ Registrar métricas de precisión (por ejemplo, coincidencia de acción).
  • ✅ Documentar limitaciones y plan de mejora continua.

Límites, errores frecuentes y cómo verificarlos

Aunque ChatGPT es potente, tiene limitaciones que debes conocer:

  • Alucinaciones: el modelo puede inventar datos. Siempre usa el Prompt 6 cuando la veracidad sea crítica.
  • Pérdida de contexto: la longitud del historial está limitada a ~8 k tokens. Implementa una estrategia de resumen periódico.
  • Sesgo de temperatura: valores altos generan creatividad pero menos consistencia. Para tareas operativas, mantén temperature ≤ 0.3.
  • Errores de formato: si la salida no respeta el JSON esperado, envía el mismo prompt con la instrucción explícita "Responde únicamente con JSON".

Una forma sencilla de comprobar la mejora es comparar métricas antes y después de cada ajuste: por ejemplo, medir la precisión del campo acción contra una lista manual.
