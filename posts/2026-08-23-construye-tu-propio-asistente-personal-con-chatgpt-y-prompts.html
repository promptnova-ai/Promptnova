Construye tu propio asistente personal con ChatGPT y prompts

Introducción

En la era de la IA, contar con un asistente personal que entienda tus necesidades es cada vez más accesible. Gracias a ChatGPT y a una buena estrategia de prompts, puedes crear una herramienta que gestione tareas, responda preguntas y automatice procesos sin necesidad de programar desde cero.

“Un buen prompt es la conversación que inicia la magia.” – Prompt Engineer

Diseñando los prompts

El corazón de cualquier asistente basado en ChatGPT son los prompts que le indican cómo debe comportarse. A continuación, veremos tres ejemplos listos para copiar.

Ejemplo 1: Asistente de agenda

Actúa como un asistente de agenda personal. Cada vez que el usuario te pida programar una cita, responde con la fecha, hora y ubicación en formato JSON:
{
  "evento": "Reunión de proyecto",
  "fecha": "2026-09-15",
  "hora": "10:00",
  "lugar": "Sala 3"
}
Mantén un tono cordial y confirma siempre la información.

Ejemplo 2: Resumen de correos

Eres un asistente que resume correos largos. Recibe el cuerpo del correo y devuelve un resumen de máximo 3 líneas, resaltando acciones a tomar. Usa viñetas si hay varios puntos.

Ejemplo 3: Búsqueda de información

Actúa como un buscador interno. Cuando el usuario solicite datos, responde con una breve explicación y una fuente fiable en formato markdown. Si no conoces la respuesta, indica que consultarás fuentes externas.

Estos prompts pueden almacenarse en variables o bases de datos y enviarse a la API según el contexto del usuario.

Integración con la API

Una vez definidos los prompts, el siguiente paso es conectar tu aplicación con la API de OpenAI. Los pasos básicos son:

  • Crear una cuenta y obtener la clave API.
  • Instalar la biblioteca cliente (por ejemplo, openai para Python).
  • Configurar una función que envíe el prompt y reciba la respuesta.
  • Manejar errores y límites de uso.

Aquí tienes un fragmento de código en Python que ilustra la llamada:

import openai, os

openai.api_key = os.getenv("OPENAI_API_KEY")

def preguntar_asistente(prompt, user_input):
    response = openai.ChatCompletion.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": prompt},
            {"role": "user", "content": user_input}
        ],
        temperature=0.7
    )
    return response.choices[0].message.content.strip()

Personalización y mejoras

Para que el asistente sea realmente útil, debes adaptarlo a tu flujo de trabajo. Algunas ideas:

  • Persistencia de contexto: guarda la conversación en una base de datos y envía los últimos mensajes en cada solicitud.
  • Multi‑idioma: incluye prompts en varios idiomas si trabajas con equipos internacionales.
  • Feedback loop: permite al usuario calificar respuestas para ajustar el tono y la precisión.

También puedes combinar ChatGPT con otras APIs (calendario, correo, tareas) mediante webhooks, creando una solución integral.

Conclusión

Construir un asistente personal con ChatGPT no es ciencia de cohetes; basta con diseñar prompts claros, integrar la API y refinar la experiencia con feedback continuo. Con los ejemplos y pasos que hemos compartido, estás listo para lanzar tu propio asistente y ahorrar tiempo en tu día a día.
