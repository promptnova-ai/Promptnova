Construye tu propio asistente personal con ChatGPT y prompts

2026-09-08 · 5 min de lectura · ChatGPT asistente personal prompt engineering

Introducción

Los asistentes personales basados en inteligencia artificial han pasado de ser un concepto de ciencia ficción a una herramienta accesible para cualquier profesional o entusiasta de la tecnología. Con la llegada de ChatGPT y la madurez de la prompt engineering, ya no es necesario contar con infraestructura compleja ni conocimientos profundos de machine learning para disponer de un agente que gestione agenda, responda correos o busque información en tiempo real.

En este artículo verás cómo diseñar, entrenar y desplegar tu propio asistente personal usando únicamente la API de OpenAI y una serie de prompts bien estructurados. Cada sección incluye ejemplos listos para copiar, advertencias sobre los límites del modelo y una checklist accionable para que puedas pasar de la teoría a la práctica en menos de una hora.

Conceptos clave

¿Qué es un asistente personal basado en IA?

Un asistente personal con IA es un programa que interpreta instrucciones en lenguaje natural, mantiene contexto y genera respuestas útiles. La diferencia con un chatbot tradicional es que el asistente está orientado a tareas concretas (gestión de calendario, recordatorios, búsquedas, etc.) y suele integrarse con APIs externas para ejecutar acciones reales.

Prompt engineering esencial

La calidad del resultado depende casi exclusivamente de cómo se formula el prompt. Los mejores prompts siguen una estructura clara: instrucción + contexto + formato de salida esperado. Esta regla se aplicará en todos los ejemplos que aparecen a continuación.

Ejemplos de prompts reutilizables

A continuación tienes entre cinco y ocho fragmentos de código listos para copiar. Cada uno está pensado para una tarea concreta dentro del asistente personal.

# Prompt 1 – Resumen de correo electrónico
You are an email assistant. Summarize the following email in 3 bullet points, keeping the tone formal and highlighting any action items.
---
{{email_body}}

Útil cuando el asistente necesita procesar mensajes entrantes y extraer tareas.

# Prompt 2 – Generación de agenda diaria
Create a daily agenda for {{date}} based on the following events and priorities. Output in a markdown table with columns: Time, Activity, Priority.
---
{{events_list}}

Ideal para construir una agenda estructurada que el usuario pueda copiar a su calendario.

# Prompt 3 – Búsqueda de información rápida
Answer the user question using only verified facts. Cite the source URL at the end of each sentence.
---
{{user_question}}

Este prompt fuerza al modelo a proporcionar referencias, reduciendo la posibilidad de alucinaciones.

# Prompt 4 – Recordatorio proactivo
Generate a friendly reminder for the user about the upcoming deadline on {{deadline_date}}. Include a short motivational tip.
---
{{task_description}}

Sirve para crear notificaciones que mantengan al usuario motivado sin ser intrusivas.

# Prompt 5 – Conversión de unidades y cálculos simples
Convert the following quantities to the metric system and provide a brief explanation of the conversion method.
---
{{raw_input}}

Útil cuando el asistente necesita realizar cálculos rápidos sin depender de una API externa.

# Prompt 6 – Generación de respuestas personalizadas
Act as a friendly personal assistant named Alex. Reply to the user query below, using a conversational tone and ending with a question to keep the dialogue flowing.
---
{{user_query}}

Mejora la experiencia conversacional al mantener la continuidad del diálogo.

Casos de uso comunes

  • Gestión de agenda y recordatorios.
  • Resumen y clasificación de correos electrónicos.
  • Asistencia en investigación y búsqueda de fuentes confiables.
  • Conversión de unidades y cálculos rápidos.
  • Generación de contenido breve (tweets, notas, listas).

Guía paso a paso: caso práctico

Vamos a crear un asistente llamado Eva que pueda:

  1. Recibir un correo y extraer tareas.
  2. Crear una agenda diaria a partir de eventos del calendario.
  3. Enviar recordatorios proactivos.

1. Configuración de la API

Regístrate en OpenAI y genera una clave API. Instala la librería oficial:

pip install openai

2. Definir los prompts

Guarda los prompts anteriores en variables o archivos JSON. Por ejemplo:

email_prompt = "You are an email assistant..."
agenda_prompt = "Create a daily agenda..."

3. Implementar la lógica de flujo

El flujo básico será:

1. Recepción del correo → Llamada a email_prompt → Obtención de tareas.
2. Consulta al calendario → Llamada a agenda_prompt → Generación de agenda.
3. Verificación de fechas límite → Llamada a recordatorio_prompt → Envío de notificación.

Un ejemplo de código en Python:

import openai, os
openai.api_key = os.getenv("OPENAI_API_KEY")

def call_gpt(prompt, user_input):
    response = openai.ChatCompletion.create(
        model="gpt-4o-mini",
        messages=[{"role": "system", "content": prompt},
                  {"role": "user", "content": user_input}],
        temperature=0.2,
    )
    return response.choices[0].message.content.strip()

# 1. Resumir correo
email_body = "..."  # texto del correo real
tasks = call_gpt(email_prompt, email_body)
print("Tareas extraídas:", tasks)

# 2. Generar agenda
events = "..."  # JSON con eventos del día
agenda = call_gpt(agenda_prompt, events)
print("Agenda del día:\n", agenda)

# 3. Recordatorio
deadline = "2026-09-15"
reminder = call_gpt(recordatorio_prompt, f"{deadline}\n{tasks}")
print(reminder)

4. Integración con servicios externos

Para que Eva envíe correos o notificaciones, conecta la salida del modelo con APIs de Gmail, Twilio o Slack. La clave está en mapear la respuesta estructurada (por ejemplo, una tabla markdown) a la API correspondiente.

5. Prueba y ajuste

Ejecuta el flujo con datos reales y verifica:

  • ¿Se extraen todas las tareas del correo?
  • ¿La agenda respeta los husos horarios?
  • ¿Los recordatorios aparecen con la antelación adecuada?

Ajusta la temperatura o añade ejemplos en el prompt si observas inconsistencias.

Checklist accionable

  • ☑️ Crear cuenta y obtener clave API de OpenAI.
  • ☑️ Instalar la librería openai en tu entorno.
  • ☑️ Definir los prompts críticos (email, agenda, recordatorio).
  • ☑️ Implementar una función genérica call_gpt que reciba prompt y entrada.
  • ☑️ Conectar el asistente con fuentes de datos (correo, calendario).
  • ☑️ Configurar canales de salida (email, Slack, notificaciones push).
  • ☑️ Realizar pruebas con casos de uso reales y anotar fallos.
  • ☑️ Ajustar prompts y parámetros (temperature, max_tokens) según resultados.

Límites y errores frecuentes

ChatGPT no tiene acceso directo a bases de datos externas ni a la web en tiempo real; cualquier información que requiera actualización debe provenir de APIs propias que alimenten el prompt.

Errores típicos:

  • Alucinaciones: El modelo inventa datos cuando no se le proporciona una fuente fiable. Solución: usar el prompt 3 que obliga a citar URLs.
  • Pérdida de contexto: Si la conversación supera los tokens permitidos, el historial se corta. Solución: resumir el contexto antes de cada llamada.
  • Respuestas demasiado largas: Ajusta max_tokens y usa instrucciones explícitas de formato corto.

Verificación de resultados

Para asegurarte de que el asistente está funcionando correctamente, sigue estos pasos de validación:

  1. Comparar la lista de tareas extraídas con el contenido original del correo.
  2. Revisar que cada fila de la agenda coincida con un evento del calendario.
  3. Comprobar que los recordatorios se envían al menos 24 h antes de la fecha límite.
  4. Ejecutar pruebas unitarias automatizadas que simulen entradas típicas y esperen salidas predefinidas.

Si los resultados cumplen con los criterios anteriores, puedes considerar que el asistente está listo para uso personal.
