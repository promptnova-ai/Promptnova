Cómo escribir prompts infalibles: Guía práctica paso a paso

2026-09-05 · 5 min de lectura · prompt engineering IA productividad

Entender el objetivo del prompt

Antes de lanzar cualquier instrucción a un modelo de IA, es fundamental definir con claridad qué se quiere obtener. Un objetivo bien delimitado reduce la ambigüedad y evita respuestas fuera de contexto.

  • ¿Cuál es la información clave que necesitas?
  • ¿En qué formato esperas la respuesta (lista, párrafo, tabla)?
  • ¿Hay restricciones de longitud o estilo?
“Un buen prompt es la pregunta correcta formulada de la manera correcta.” – Prompt Engineer

Estructura de un prompt eficaz

Una estructura típica que funciona en la mayoría de los casos incluye:

  1. Contexto breve: Proporciona la información esencial.
  2. Instrucción clara: Usa verbos de acción como "explica", "resume", "compara".
  3. Formato de salida: Especifica si deseas una tabla, viñetas, código, etc.
  4. Ejemplo (opcional): Un pequeño ejemplo guía al modelo.

Plantilla reutilizable

Una plantilla que puedes copiar y adaptar rápidamente:

Contexto: [Información relevante]
Instrucción: [Qué debe hacer el modelo]
Formato: [lista, tabla, párrafo, código]
Ejemplo: [Opcional]

Errores comunes y cómo evitarlos

Muchos prompts fallan por motivos simples pero evitables:

  • Ambigüedad: Preguntas vagas generan respuestas vagas.
  • Sobrecarga de información: Demasiado contexto confunde al modelo.
  • Falta de formato: Sin especificar el tipo de salida, la respuesta puede no ser utilizable.

Revisa siempre tu prompt con estas preguntas:

  • ¿He sido específico?
  • ¿He indicado el formato deseado?
  • ¿He limitado la longitud si es necesario?

Ejemplos de prompts infalibles

A continuación tres ejemplos listos para copiar. Cada uno sigue la estructura recomendada y muestra cómo adaptar la plantilla a diferentes casos de uso.

Ejemplo 1: Resumen ejecutivo

Contexto: Artículo reciente sobre "Inteligencia Artificial" publicado en "Tech Today".
Instrucción: Resume los puntos clave del artículo en español, enfocándote en las implicaciones éticas.
Formato: Párrafo de 150 palabras máximo.
Ejemplo: "El artículo destaca que..."

Ejemplo 2: Generación de tabla comparativa

Contexto: Necesito comparar tres modelos de lenguaje (GPT‑4, Claude, LLaMA).
Instrucción: Crea una tabla que incluya: capacidad de tokens, costo por 1 000 tokens, y casos de uso recomendados.
Formato: Tabla en formato markdown.
Ejemplo:
| Modelo | Tokens | Costo | Uso recomendado |
|--------|--------|-------|-----------------|
| GPT‑4  | 8 192  | $0.03 | Asistentes avanzados |
| Claude | 100 000| $0.02 | Diálogos extensos |
| LLaMA  | 4 096  | $0.01 | Investigación académica |

Ejemplo 3: Código funcional

Contexto: Necesito una función en Python que convierta una lista de fechas en formato ISO a objetos datetime.
Instrucción: Escribe el código con manejo de errores y comentarios explicativos.
Formato: Bloque de código puro, sin markdown.
Ejemplo:
import datetime

def iso_to_datetime(dates):
    result = []
    for d in dates:
        try:
            result.append(datetime.datetime.fromisoformat(d))
        except ValueError:
            result.append(None)  # Valor no válido
    return result

Con estos ejemplos y la guía anterior, podrás crear prompts que rara vez fallan y que siempre entregan resultados precisos y útiles.
