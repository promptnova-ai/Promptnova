Errores comunes al escribir prompts y cómo evitarlos

2026-11-13 · 5 min de lectura · prompt engineering IA errores comunes

Introducción

Los modelos de lenguaje como ChatGPT pueden producir resultados sorprendentes, pero su rendimiento depende en gran medida de la calidad del prompt. Un prompt confuso, vago o mal estructurado suele generar respuestas irrelevantes, incompletas o sesgadas. En este artículo analizamos los errores más habituales al redactar prompts y ofrecemos técnicas concretas para evitarlos, con ejemplos listos para copiar y un caso práctico paso a paso.

1. Principales errores al redactar prompts

1.1. Falta de contexto

Cuando el modelo no dispone de la información necesaria, tiende a adivinar. Un prompt que dice "Escribe un artículo sobre IA" es demasiado amplio; el modelo no sabrá el tono, la audiencia o la extensión deseada.

1.2. Ambigüedad en la instrucción

Los enunciados que pueden interpretarse de varias maneras provocan respuestas inconsistentes. Por ejemplo, "Explica la diferencia entre IA y ML" puede generar una definición muy breve o un análisis profundo, según lo que el modelo entienda como "explicar".

1.3. Instrucciones contradictorias

Combinar peticiones opuestas, como "escribe un texto formal pero con lenguaje coloquial", confunde al modelo y suele producir un resultado intermedio que no satisface ninguna de las dos demandas.

1.4. Ignorar el límite de tokens

Solicitar un artículo de 2000 palabras sin especificar la longitud máxima puede generar respuestas truncadas o incompletas, ya que el modelo tiene un límite de tokens por petición.

1.5. No indicar formato de salida

Si necesitas una lista, una tabla o código, debes indicarlo explícitamente. De lo contrario, el modelo puede devolver párrafos corridos que tendrás que re‑formatear manualmente.

2. Ejemplos de prompts bien estructurados

A continuación se presentan ocho ejemplos que ilustran cómo aplicar los principios anteriores. Cada bloque está listo para copiar.

/* 1. Prompt con contexto y tono */
Escribe un artículo de 800 palabras dirigido a profesionales de marketing que explique los riesgos de sesgo algorítmico. Usa un tono formal, incluye al menos tres ejemplos reales y finaliza con una lista de buenas prácticas.
/* 2. Prompt que delimita formato */
Genera una tabla Markdown con tres columnas: "Herramienta", "Ventaja" y "Desventaja". Incluye cinco herramientas de generación de texto y proporciona una breve descripción en cada celda.
/* 3. Prompt con paso a paso */
Describe paso a paso cómo entrenar un modelo de clasificación de sentimientos con Python y scikit‑learn. Cada paso debe contener un fragmento de código funcional y una breve explicación.
/* 4. Prompt que evita ambigüedad */
Resume en 150 palabras los principales hallazgos del artículo "Attention Is All You Need" (Vaswani et al., 2017). Enfócate en la arquitectura Transformer y menciona por qué revolucionó el campo del NLP.
/* 5. Prompt con límite de tokens */
Escribe una introducción de máximo 120 palabras para un blog sobre ética de la IA. No excedas 200 tokens y termina con una pregunta que invite a comentar.
/* 6. Prompt con verificación de resultados */
Crea una lista de cinco métricas para evaluar la calidad de respuestas generadas por un modelo de lenguaje. Después, escribe una breve guía de cómo validar cada métrica con ejemplos numéricos.
/* 7. Prompt que combina datos y narrativa */
Utiliza los siguientes datos de ventas (Ene: 1200, Feb: 1350, Mar: 1580) y escribe un breve informe ejecutivo que destaque la tendencia, incluya una conclusión y sugiera una acción para el próximo trimestre.
/* 8. Prompt para depurar código */
Revisa el siguiente fragmento de Python y corrige los errores sintácticos y lógicos. Añade comentarios explicando cada corrección.

```python
import math

def area_circulo(radio):
    return math.pi * radio**2

print(area_circulo('5'))
```

3. Caso práctico: de la idea al prompt final

Supongamos que trabajas en una startup y necesitas generar una guía de buenas prácticas para redactar prompts que será publicada en el blog interno.

3.1. Definir objetivo y audiencia

  • Objetivo: enseñar a empleados sin experiencia en IA a crear prompts claros.
  • Audiencia: equipos de producto y marketing.
  • Extensión: 1200 palabras.
  • Formato: artículo con secciones, ejemplos y checklist.

3.2. Recopilar requisitos

Se decide incluir:

  • Errores comunes.
  • Ejemplos de prompts correctos.
  • Procedimiento de validación.
  • Checklist para revisión.

3.3. Redactar el prompt maestro

Escribe un artículo de 1200 palabras dirigido a empleados de una startup que explique los errores más habituales al crear prompts para modelos de lenguaje. Incluye:
- Una introducción breve.
- Tres secciones con ejemplos reales (5‑8 bloques de código) que muestren cómo corregir cada error.
- Un caso práctico paso a paso que cubra desde la idea inicial hasta el prompt final.
- Una checklist accionable de 10 ítems.
- Una sección de fuentes con enlaces a la documentación oficial de OpenAI y a la guía de Prompt Engineering de DeepLearning.ai.
Utiliza un tono ameno, profesional y sin promesas de resultados garantizados. Formatea el artículo con HTML semántico (h2, h3, p, ul, li, blockquote, pre, code). No incluyas estilos inline.

3.4. Ejecutar y revisar

Se envía el prompt a ChatGPT, se revisa la respuesta y se ajusta la longitud usando la instrucción "no excedas 2000 tokens". Finalmente, se valida que cada bloque de código sea ejecutable y que los enlaces apunten a recursos reales.

4. Checklist accionable

  • ✅ Define claramente el objetivo y la audiencia.
  • ✅ Proporciona contexto suficiente (tema, tono, extensión).
  • ✅ Especifica el formato de salida (lista, tabla, código).
  • ✅ Evita ambigüedades usando palabras precisas.
  • ✅ No combines instrucciones contradictorias.
  • ✅ Limita la longitud con un máximo de tokens o palabras.
  • ✅ Incluye ejemplos de salida esperada.
  • ✅ Prueba el prompt y revisa la respuesta.
  • ✅ Ajusta según los errores detectados.
  • ✅ Documenta versiones y cambios para futura referencia.

5. Límites, errores frecuentes y verificación de resultados

Incluso con un prompt perfectamente estructurado, los modelos pueden producir información desactualizada o inventar datos (hallucination). Por ello es esencial:

  • Verificar fuentes: siempre cruza datos con documentos oficiales.
  • Controlar sesgos: revisa que el texto no favorezca inadvertidamente una perspectiva.
  • Re‑evaluar token‑budget: si la respuesta se corta, reduce la longitud solicitada o divide la tarea en sub‑prompts.
  • Usar validaciones automáticas: scripts que comprueben formato JSON, presencia de palabras clave o número de ítems.
“Un buen prompt no elimina la necesidad de revisión humana, pero sí reduce la carga de trabajo y aumenta la consistencia.”
