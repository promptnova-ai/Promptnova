Prompt engineering para developers: trucos que no conocías

2026-08-20 · 5 min de lectura · prompt engineering developers IA

Introducción al prompt engineering

El prompt engineering se ha convertido en una habilidad esencial para cualquier developer que trabaje con modelos de lenguaje. No se trata solo de escribir preguntas, sino de diseñar instrucciones que guíen al modelo a producir respuestas precisas, eficientes y alineadas con los objetivos del proyecto.

"Un buen prompt es como un contrato: define claramente lo que esperas y lo que obtendrás"

Truco 1: Usa delimitadores claros

Separar la descripción del contexto, la tarea y los ejemplos con delimitadores (---, ###, o etiquetas JSON) ayuda al modelo a distinguir cada sección. Esto reduce ambigüedades y mejora la consistencia.

"""
  Contexto:
  ---
  Eres un asistente que ayuda a generar código Python para manipular datos en pandas.
  ---
  Tarea:
  - Dada una tabla CSV, crea una función que filtre filas por una columna específica.
  ---
  Ejemplo de entrada:
  {\"file\": \"ventas.csv\", \"columna\": \"region\", \"valor\": \"Norte\"}
  """

Truco 2: Cadena de pensamiento (Chain‑of‑Thought)

Al pedir al modelo que explique su razonamiento paso a paso, obtienes resultados más fiables, sobre todo en tareas complejas como depuración o generación de algoritmos.

"""
  Resuelve el siguiente problema paso a paso:
  - Dado un array de números, devuelve los que sean primos.
  - Primero, escribe la lógica para identificar un número primo.
  - Después, aplica esa lógica al array.
  """

Ejemplo práctico

Supongamos que necesitas un snippet de JavaScript que elimine duplicados de un array.

"""
  // Paso 1: Explicar la estrategia
  // Paso 2: Mostrar el código
  const eliminarDuplicados = (arr) => {
    // Usamos Set para garantizar unicidad
    return [...new Set(arr)];
  };
  """

Truco 3: Instrucciones de formato estructurado

Cuando tu aplicación necesita que la salida sea parseable (JSON, YAML, CSV), indica explícitamente el formato y valida con un ejemplo.

"""
  Genera la respuesta en JSON con los campos: nombre, edad, habilidades (lista).
  Ejemplo:
  {\"nombre\": \"Ana\", \"edad\": 29, \"habilidades\": [\"Python\", \"Docker\"]}
  """

Truco 4: Re‑uso de prompts mediante variables

En entornos de desarrollo, almacenar plantillas de prompt con placeholders permite reutilizarlos rápidamente. Usa sintaxis como {{variable}} y reemplázala en tiempo de ejecución.

  • Plantilla base: "Eres un experto en {{tecnologia}}. Explica cómo usar {{funcion}} con ejemplos."
  • Reemplazo: tecnología = "Node.js", función = "fs.readFile".

Truco 5: Prompt chaining (encadenamiento)

Divide una tarea compleja en varios prompts encadenados. El resultado del primer paso alimenta al siguiente, creando un flujo de trabajo controlado.

"""
  Paso 1: Extrae los requisitos funcionales de este documento.
  Paso 2: Con los requisitos, genera un diagrama de flujo en mermaid.
  Paso 3: A partir del diagrama, escribe el código skeleton en Python.
  """

Conclusión

Dominar estos trucos permite a los developers exprimir al máximo el potencial de los LLMs, reduciendo tiempo de desarrollo y mejorando la calidad del código generado. Experimenta, mide y ajusta cada prompt: la práctica constante es la clave.
